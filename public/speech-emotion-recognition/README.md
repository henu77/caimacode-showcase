# 基于深度学习的语音情感识别系统

## 项目简介
本项目是一个面向语音情感分类任务的深度学习实践项目，使用 PyTorch 完成数据处理、模型训练、结果评估与界面演示的完整流程。系统以语音片段为输入，对情感状态进行分类，当前识别类别包括愤怒、恐惧、开心、中性、悲伤和惊讶六类。

从源码结构和功能组织来看，该项目更适合作为本科课程设计或教学案例展示：一方面覆盖了从数据准备到模型部署演示的完整链路，另一方面保留了训练脚本、评价图表和桌面交互界面，便于说明实现过程与实验结果。

## 项目背景与目标
语音不仅承载文本信息，也包含说话人的情感线索。语音情感识别任务的目标，是从音频信号中提取有效特征并完成情感分类。本项目围绕这一任务，尝试比较不同输入表示和网络结构在小规模数据集上的表现，并提供可直接演示的界面程序。

本项目的目标主要包括：

- 建立统一的数据准备、训练、验证与测试流程；
- 支持原始波形和 MFCC 频谱图两种输入形式；
- 使用 ResNet 系列模型完成六分类情感识别；
- 输出多种评估指标与可视化图表；
- 提供图形界面，支持本地音频和实时录音预测。

## 核心功能
### 1. 数据处理与划分
项目提供独立的数据处理脚本，用于将原始 `wav` 数据集划分为训练集和验证集。数据组织方式按情感类别分目录存放，便于后续由 `Dataset` 类统一读取。

在音频预处理阶段，系统完成了以下步骤：

- 将多通道音频转换为单声道；
- 重采样到 16kHz；
- 将音频裁剪或填充到 1.5 秒；
- 在需要时提取 MFCC 特征，并统一调整输入尺寸。

### 2. 多输入建模方案
项目实现了两类情感识别建模方式：

- **原始波形建模**：基于 1D ResNet 结构，直接对时间序列波形建模；
- **MFCC 频谱图建模**：先提取 MFCC 特征，再使用改造后的二维 ResNet 进行分类。

这种设计使项目不仅完成了基本分类任务，也体现出对不同特征表达方式的实验对比思路。

### 3. 模型训练与评估
训练脚本支持批大小、训练轮数、学习率、优化器、预训练权重和学习率调度器等参数配置。训练结束后，项目会自动输出：

- Loss 曲线；
- Accuracy 曲线；
- Precision 曲线；
- Recall 曲线；
- F1 曲线；
- 混淆矩阵；
- PR 曲线；
- 测试结果汇总文件。

这使项目结果不仅停留在单一准确率指标上，而是能够从多角度分析分类效果。

### 4. 图形界面演示
项目提供基于 PyQt5 的桌面端界面，支持以下展示场景：

- 加载本地音频文件进行预测；
- 播放音频并查看识别结果；
- 使用麦克风实时录音；
- 通过后台线程进行周期性情感预测；
- 在界面中显示识别状态与结果反馈。

对课程设计展示而言，图形界面部分能显著提升项目可演示性，使模型结果不只停留在命令行输出层面。

## 技术栈与系统结构
### 技术栈
- Python
- PyTorch / TorchVision / TorchAudio
- NumPy
- scikit-learn
- Matplotlib / Seaborn

### 系统结构
项目整体可以分为四个部分：

1. **数据准备层**：原始语音数据划分、目录整理与预处理；
2. **模型训练层**：构建数据加载器、选择模型、执行训练与验证；
3. **结果评估层**：输出指标、保存最优模型、绘制图表；
4. **应用演示层**：通过桌面 GUI 调用模型完成预测展示。

## 关键实现
### 1. 统一音频预处理流程
项目在训练和预测阶段共用相近的数据处理逻辑，保证输入分布基本一致。对于长度不足的语音做补零处理，对于过长语音进行随机裁剪，有助于形成固定尺寸输入。

### 2. 波形模型与频谱模型并行支持
项目没有只固定一种建模方式，而是保留原始波形和 MFCC 两条实验路径。这样的实现更符合课程设计中“方案比较”的表达方式，也有利于说明不同输入表示对识别效果的影响。

### 3. 评估图表自动生成
训练脚本在保存模型的同时输出多种可视化图表，降低了实验结果整理成本。对于展示型项目而言，这些图像可以直接作为结果页素材使用。

### 4. 实时预测线程设计
界面程序将录音与预测放在独立线程中处理，避免阻塞主界面。这一设计说明项目不仅关注模型本身，也考虑了交互体验与程序结构的完整性。

## 难点与解决方案
### 1. 音频长度不一致
不同语音样本时长存在差异，无法直接输入神经网络。项目通过裁剪与补零，将输入统一到固定长度，解决了批量训练中的尺寸不一致问题。

### 2. 原始波形与频谱图输入形式不同
一维波形与二维特征图对应不同网络结构。项目分别实现 1D ResNet 和基于视觉模型改造的频谱图 ResNet，使两类输入都能纳入统一训练框架。

### 3. 小规模数据集下的结果表达
在样本量有限的情况下，仅用准确率难以完整反映模型性能。项目补充了精确率、召回率、F1、混淆矩阵和 PR 曲线，用于更全面地展示识别效果。

### 4. 模型展示与交互演示脱节
很多实验项目止步于训练脚本，本项目进一步提供 GUI 界面，将模型结果转化为可操作的演示流程，增强了项目展示完整度。

## 项目结果
根据源码仓库中的 README 说明，项目给出了两组典型实验结果：

- ResNet18 + MFCC 频谱图：准确率约 73.3%，F1 得分约 74.4%；
- ResNet18 + 原始波形：准确率约 80.0%，F1 得分约 78.0%。
