# 基于深度学习的语音情感识别系统

## 项目简介

这是一个完整的语音情感识别课程设计项目，从数据处理、模型训练到最终的交互演示，涵盖了深度学习项目的全流程。项目使用 PyTorch 框架，以语音片段作为输入，能够识别六种不同的情感类别：愤怒、恐惧、开心、中性、悲伤和惊讶。

整个项目的设计初衷是为了展示如何将深度学习模型从研究阶段转化为可实际演示的应用。不仅包含了完整的训练脚本和数据处理流程，还提供了基于 PyQt5 的桌面应用界面，使得模型的效果能够直观地展现出来，非常适合作为本科课程设计或毕业设计的展示案例。

## 项目背景

语音是人类最自然的交流方式，它不仅承载着文本信息，更重要的是蕴含了说话人的情感特征。从语音中识别出说话人的情感状态，这个任务在人机交互、客服系统、心理健康监测等领域都有实际应用价值。

这个项目的核心目标就是从音频信号中提取有效的特征，然后通过神经网络完成情感分类。在实现过程中，我们尝试了不同的输入表示方式（原始波形和频谱特征）和网络结构，在相对较小的数据集上进行了对比实验，最终得到了可用的模型和演示系统。

## 核心功能模块

### 数据处理与准备

项目从原始的 wav 音频文件开始处理。首先将数据按照情感类别组织到不同的文件夹中，然后进行统一的划分，分出训练集和验证集。

在音频预处理阶段，需要处理的问题包括：**多通道音频的转换**（统一为单声道）、**采样率的标准化**（重采样到 16kHz）、以及**长度的统一**（将所有音频裁剪或填充到 1.5 秒）。这些预处理步骤看似简单，但对最终的模型效果影响很大。

此外，项目还支持 **MFCC 特征的提取**，这是一种常用的音频特征表示方法，能够更好地捕捉人类听觉系统的特性。提取后的特征会被统一调整到相同的尺寸，以便输入到神经网络中。

### 多种建模方案

项目实现了两种不同的建模思路，这样做的目的是为了对比不同的特征表示方式对识别效果的影响。

**第一种方案是直接使用原始波形**。这种方法基于 1D ResNet 网络结构，直接对时间序列的波形数据进行建模。优点是不需要额外的特征提取步骤，能够保留原始信号的所有信息。

**第二种方案是先提取 MFCC 特征，再进行建模**。这种方法将音频转换为二维的频谱图，然后使用改造后的二维 ResNet 进行分类。这种方法的好处是特征更加紧凑，能够突出音频中对人类听觉重要的部分。

通过对比这两种方案的效果，可以更深入地理解不同特征表示对模型性能的影响，这也是课程设计中”方案对比”的重要体现。

### 训练与评估

训练脚本提供了丰富的参数配置选项，包括批大小、训练轮数、学习率、优化器的选择，甚至还支持预训练权重和学习率调度器等高级特性。

训练完成后，项目会自动生成多种评估指标和可视化图表。除了基本的准确率，还包括精确率、召回率和 F1 分数等指标，这些指标能够从不同角度反映模型的性能。同时生成的 **Loss 曲线**、**Accuracy 曲线**、**混淆矩阵**和 **PR 曲线**等图表，能够帮助我们更直观地理解模型的学习过程和分类效果。

### 交互式演示界面

项目提供了一个基于 PyQt5 的桌面应用界面，这是整个项目中最能体现”可演示性”的部分。

用户可以通过这个界面**加载本地的音频文件**进行预测，系统会播放音频并显示识别结果。更有趣的是，用户还可以**使用麦克风进行实时录音**，系统会在后台线程中持续进行情感识别，并将结果实时反馈到界面上。这种交互方式使得模型的效果不再仅仅停留在命令行的数字输出，而是能够通过图形界面直观地展现出来。

## 技术选型

整个项目的技术栈相对清晰：

- **深度学习框架**：PyTorch，以及配套的 TorchVision 和 TorchAudio 库
- **数据处理**：NumPy 用于数值计算，scikit-learn 用于数据划分和评估指标计算
- **可视化**：Matplotlib 和 Seaborn 用于绘制各种图表
- **图形界面**：PyQt5 用于开发桌面应用

这些库的组合选择既保证了功能的完整性，又避免了过度复杂化。

## 项目架构

从整体的组织结构来看，项目可以分为四个层次：

**数据准备层**负责原始语音数据的划分、目录整理和预处理。这一层的输出是标准化的、可以直接用于训练的数据集。

**模型训练层**包含数据加载器的构建、模型的选择和初始化、以及训练与验证的执行。这一层是项目的核心，决定了最终模型的质量。

**结果评估层**在训练完成后工作，负责计算各种评估指标、保存最优的模型权重，以及绘制各种可视化图表。这一层的输出是可以直接用于报告和展示的结果。

**应用演示层**通过桌面 GUI 调用已训练的模型，完成实际的预测演示。这一层是用户与模型交互的接口。

## 实现细节

### 统一的音频预处理

在训练和预测阶段，项目使用了相同的数据处理逻辑。这样做的好处是能够保证训练数据和预测数据的分布基本一致，避免了因为预处理方式不同而导致的性能下降。

对于长度不足的语音，项目采用补零的方式进行填充。对于过长的语音，则采用随机裁剪的方式。这样处理后，所有的音频都被转换成了固定长度的输入，可以直接用于批量训练。

### 两条并行的实验路径

项目没有只选择一种建模方式，而是同时保留了原始波形和 MFCC 两条实验路径。这种设计既体现了课程设计中”方案对比”的要求，也能够帮助我们理解不同特征表示对识别效果的具体影响。

### 自动化的评估与可视化

训练脚本在保存模型的同时，会自动生成各种可视化图表。这大大降低了实验结果整理的成本，生成的图表可以直接用作项目报告或展示的素材。

### 独立线程的实时预测

在桌面应用中，录音和预测的操作被放在了独立的线程中处理。这样做的好处是不会阻塞主界面的响应，用户可以在预测进行的同时继续与界面交互。这个设计细节虽然看起来不起眼，但体现了对用户体验的考虑。

## 遇到的主要问题与解决方案

### 音频长度的不一致性

不同的语音样本时长存在差异，这是一个很现实的问题。神经网络需要固定大小的输入，无法直接处理长度不一的音频。

解决方案是通过**裁剪和补零**的方式，将所有音频统一到固定长度。对于过长的音频进行随机裁剪，对于过短的音频进行零值填充。这样处理后，就可以进行批量训练了。

### 不同输入形式的模型设计

原始波形是一维的时间序列，而 MFCC 特征是二维的频谱图。这两种输入形式对应不同的网络结构。

为了支持两种输入形式，项目分别实现了 1D ResNet（用于波形）和改造后的二维 ResNet（用于频谱图）。这样两种输入都能纳入统一的训练框架中。

### 小规模数据集的评估

在样本量有限的情况下，仅用准确率这一个指标难以完整反映模型的性能。模型可能在某些类别上表现很好，在其他类别上表现较差，单一的准确率指标无法反映这种差异。

解决方案是补充了更多的评估指标，包括精确率、召回率、F1 分数、混淆矩阵和 PR 曲线。通过这些指标，可以更全面地了解模型在各个情感类别上的表现。

### 模型展示与实际演示的脱节

很多深度学习项目止步于训练脚本，模型的效果只能通过命令行输出的数字来理解。这对于课程设计的展示来说是不够的。

项目进一步提供了 PyQt5 图形界面，将模型的预测结果转化为可操作的、可交互的演示流程。这大大增强了项目的展示完整度和说服力。

## 实验结果

项目在两种建模方案上都进行了实验，得到了以下典型结果：

**ResNet18 + MFCC 频谱图方案**：在验证集上的准确率约为 73.3%，F1 得分约为 74.4%。

**ResNet18 + 原始波形方案**：在验证集上的准确率约为 80.0%，F1 得分约为 78.0%。

从这两个结果可以看出，直接使用原始波形进行建模的效果要优于先提取 MFCC 特征再建模的方案。这个发现本身就很有意义，说明在这个特定的任务和数据集上，保留原始信号的所有信息比使用人工设计的特征更有效。

## 关键画面展示

### 系统主界面

这是整个应用的核心交互界面。用户可以在这里加载本地的音频文件，系统会播放音频并显示识别结果。界面设计简洁直观，清晰地展示了本地音频预测、实时录音识别等功能入口。

除了加载文件进行预测，用户还可以点击”录音”按钮，使用麦克风进行实时录音。系统会在后台持续进行情感识别，并将识别结果实时反馈到界面上。这种交互方式使得模型的效果能够直观地展现出来。

![系统主界面](./public/speech-emotion-recognition/gallery/01-ui-home.png)

### 混淆矩阵

混淆矩阵是评估多分类模型的重要工具。在这个六分类的情感识别任务中，混淆矩阵清晰地展示了模型对各个情感类别的判别效果。

通过观察混淆矩阵，可以发现模型在某些情感类别上的表现特别好（对角线元素较大），而在某些类别对之间容易混淆（非对角线元素较大）。这些信息对于理解模型的优缺点、进一步改进模型都很有帮助。

![混淆矩阵](./public/speech-emotion-recognition/gallery/02-confusion-matrix.png)

### 准确率变化曲线

这条曲线展示了模型在训练和验证过程中准确率的变化趋势。通过观察这条曲线，可以判断模型是否出现了过拟合或欠拟合的现象。

如果训练准确率持续上升而验证准确率停滞不前，说明模型可能过拟合了。如果两条曲线都比较平坦，说明模型可能欠拟合了。在这个项目中，两条曲线都呈现出良好的上升趋势，说明模型的学习过程是有效的。

![准确率变化曲线](./public/speech-emotion-recognition/gallery/03-accuracy-curve.png)

### Precision-Recall 曲线

PR 曲线是评估分类模型在不同阈值下性能的工具。在这个项目中，为每个情感类别都绘制了对应的 PR 曲线。

曲线越接近右上角，说明模型的性能越好。通过观察不同类别的 PR 曲线，可以看出模型在不同情感类别上的表现差异。有些类别的曲线接近右上角，说明模型对这些类别的识别效果很好；而有些类别的曲线则相对靠下，说明模型在这些类别上还有改进的空间。

![Precision-Recall 曲线](./public/speech-emotion-recognition/gallery/04-pr-curve.png)
