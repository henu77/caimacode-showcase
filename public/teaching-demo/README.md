# 教学案例展示

## 内容概览

这个案例页可以用于展示某个编程教学项目，例如网页实战、组件练习、布局作品或者交互 Demo。

## 推荐展示内容

- 项目目标与亮点
- 页面截图或关键步骤图片
- B 站演示视频
- 技术栈与开发总结

## 目录结构

当前案例内容已经集中到 `public/teaching-demo/`：

- `project.json`：项目展示配置
- `README.md`：详情页说明
- `cover.svg`：项目封面
- `gallery/*`：案例截图

## 可替换字段

- 标题
- 封面
- 标签
- README 说明
- 图库与 B 站视频地址
